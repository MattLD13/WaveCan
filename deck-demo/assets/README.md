# Bundled reference assets

`LUSNoDownlink.png` is copied from Lehigh University Space Initiative’s public `urc_software` repository at `urcAssets/LUSNoDownlink.png`:

https://github.com/Lehigh-University-Space-Initiative/urc_software/blob/main/urcAssets/LUSNoDownlink.png

The app displays it only for the explicit simulated no-downlink state. It is not used as the normal LUSI product mark.

`steamdeckFront.svg` is Valve’s official front line art downloaded from the Steamworks [Steam Deck SVG Line Art](https://partner.steamgames.com/doc/steamhardware/steamdeck/svg) page. It is a reference for the LCD hardware mockup preview and is not application branding.
